# 界面设计规范

> 依据 taste 决策流程产出。**风格基因：主 = 瑞士平面（暗色变体，提供结构）＋ 辅 = 巴洛克聚光（只取「单一光源」一层，提供焦点）**。
> 一句话自检：*暗色瑞士网格上，一束暖光只照在「当前正在跑的那件事」上。*

## 1. 情绪定位（为什么是这个方向）

| 问题 | 回答 |
|---|---|
| 用户该感受到什么？ | **精密仪器的掌控感**——我知道它在干什么、还剩多久、用了多少显存 |
| 不该感受到什么？ | 「又一个 AI 味的蓝紫渐变后台」；也不该是「赛博霓虹游戏 HUD」的吵闹 |
| 界面隐喻 | 一台放在暗房里的专业仪表 + 一条正在推进的胶片 |

**明确拒绝的默认审美**：通用卡片堆叠、蓝紫渐变、玻璃拟态、大圆角胶囊、无意义发光、emoji 当图标。

## 2. 基因翻译（五基因位）

| 基因位 | 主基因（瑞士平面）给什么 | 辅基因（聚光）只取什么 | 落地 |
|---|---|---|---|
| 色彩 | 极低彩度、灰阶三级 | 唯一暖色「光」 | 4 色封顶，见 §3 |
| 光 | flat，无阴影无渐变 | **单一光源**：暗场中只有焦点区被照亮 | 只用一处 radial 暖光，面积极小 |
| 形 | **零圆角 / 2px 微圆角**、1px 细线 | 卡片「受光面更亮」而非投影 | 不用阴影，用底色差分层 |
| 字 | 一家无衬线到底、四级字号阶梯、左对齐统治 | 关键数字放大 | Inter + 等宽做数据面 |
| 构图 | 12 列栅格、大号序号做锚点、留白 32px 起 | 一屏一主角 | 主区单一焦点，不并置多个英雄 |

> **只混一层**：辅基因只贡献「光」这一个维度。**不采用**它的暖褐底色、8px 圆角、衬线标题——否则会与瑞士平面的 flat/零圆角/无衬线打架，变成两种笔触混杂（taste 红线）。

## 3. 设计 Token

```css
:root {
  /* —— 色彩：4 色封顶 —— */
  --ink:        #0A0B0D;   /* 底：近黑（禁纯黑 #000，屏幕会发死） */
  --surface:    #14171B;   /* 面：石墨（卡片/面板） */
  --surface-hi: #1B1F25;   /* 受光面：仅 hover/active/焦点卡 */
  --bone:       #E9E6E0;   /* 正文骨白（暖白，不用 #FFF） */
  --bone-dim:   #9AA0A6;   /* 次级文字 */
  --bone-mute:  #666C73;   /* 三级/占位 */
  --line:       #23272E;   /* 1px 分隔线 */
  --line-hi:    #343941;   /* 强调分隔线/边框 hover */
  --lamp:       #C9A227;   /* 唯一强调色：琥珀「灯光」 */

  /* 语义色只借用强调位，不新增色相 */
  --ok:   var(--bone-dim);        /* 成功不撒绿，用对勾+亮度 */
  --warn: var(--lamp);            /* 警告=琥珀 */
  --fail: #B4433A;                /* 失败红：仅图标与 1px 边，不铺底 */

  /* —— 光：唯一一处 —— */
  --lamp-glow: radial-gradient(ellipse at 30% 0%, rgba(201,162,39,.10), transparent 62%);

  /* —— 形 —— */
  --radius: 2px;                  /* 全局唯一圆角，禁止其他值 */
  --hairline: 1px solid var(--line);
  --no-shadow: none;              /* 本项目禁用 box-shadow 做层级 */

  /* —— 字 —— */
  --font-ui: 'Inter','Geist','Noto Sans SC',system-ui,sans-serif;
  --font-mono: 'JetBrains Mono','SFMono-Regular','Cascadia Mono',monospace;

  /* 四级字号阶梯（瑞士：少而稳） */
  --fs-display: 32px;  /* 页面主标题 */
  --fs-title:   20px;  /* 区块标题 */
  --fs-body:    14px;  /* 正文 */
  --fs-micro:   11px;  /* 标签/元数据/时间码（配等宽） */

  /* —— 间距：8 的倍数，留白 32 起 —— */
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px;
  --sp-6: 24px; --sp-8: 32px; --sp-12: 48px; --sp-16: 64px;

  /* —— 栅格 —— */
  --grid-cols: 12; --grid-gap: 24px; --sidebar-w: 240px;
}
```

**规则**
- 强调色 `--lamp` 面积 ≤ 8%：只用于**当前任务进度条填充**、**焦点卡左侧 2px 竖线**、**关键数字**、**主按钮**。
- 禁止 `box-shadow` 做层级；层级只靠 `--surface` / `--surface-hi` / `--line` 三件套。
- 禁止渐变按钮、禁止 `border-radius: 9999px` 胶囊（唯一例外：状态圆点 6px 圆形）。
- 深色底上文字对比度 ≥ 4.5:1（`--bone` on `--ink` ≈ 14:1，`--bone-dim` ≈ 5.6:1）。

## 4. 排版

| 元素 | 规范 |
|---|---|
| 页面主标题 | `--fs-display` / 700 / 字距 `-0.02em` / 左对齐 |
| 区块标题 | `--fs-title` / 600 |
| 正文 | `--fs-body` / 400 / 行高 1.55 |
| 元数据（时间码、显存、模型名） | `--fs-micro` / 等宽 / `--bone-mute` |
| 大号序号锚点 | `--fs-display` 的 2 倍（64px）/ 300 字重 / `--line-hi` 色 / 做左侧导航锚 |
| 时间码 | 一律等宽 `HH:MM:SS`，右对齐于段落左侧固定列 |

**中文排版**：中文用 Noto Sans SC；中英混排时空格由 CSS `text-spacing-trim` + 手工 ` ` 控制在数字与单位之间（`12 GB`、`128/240 段`）。

## 5. 布局

```
┌──────────────┬──────────────────────────────────────────────┐
│ 左侧栏 240px  │  主区（12 列栅格，最大内容宽 1040px，居中偏左）   │
│              │                                              │
│ STEMSCRIBE   │  页面主标题                        [主操作]     │
│ ─────────    │  ─────────────────────────────────────────   │
│ ▸ 新建任务    │                                              │
│ ▸ 资料库      │  内容                                          │
│ ▸ 模型中心    │                                              │
│ ▸ 设置        │                                              │
│              │                                              │
│ ─────────    │                                              │
│ GPU 8.1/12G  │                                              │
│ cuda12 · 就绪 │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

- 左栏固定 240px，底部常驻**资源条**（显存 + 当前后端）——这是「掌控感」的来源，永不隐藏。
- 主区左对齐，最大宽 1040px；不用居中对称构图（瑞士平面禁止居中长文本）。
- 分隔一律 1px `--line`；不使用卡片阴影堆叠，卡片= `--surface` + 1px 边 + 2px 圆角。

## 6. 「单一聚光」怎么用（辅基因的唯一落点）

只在**三个瞬间**出现暖光，其余全程 flat：

| 场景 | 光的表现 |
|---|---|
| **运行中的任务卡** | 卡片顶部 `--lamp-glow` 一层极淡暖光（opacity ≤ 0.10），配 2px 琥珀左竖线；表示「这台机器正在为这件事发热」 |
| **空态主按钮** | 按钮周围 1 层径向光晕（≤ 0.08），把目光引到「开始第一件事」 |
| **完成瞬间** | 进度条填满后 200 ms 内琥珀色亮度脉冲一次即止（不循环、不庆祝动画） |

> 其余所有地方**禁止**加光：不发光的分隔线、发光文字、发光边框。聚光之所以有效，是因为它是唯一。

## 7. 页面清单与关键交互

| 页面 | 核心内容 | 关键交互 |
|---|---|---|
| **首次向导** | 4 步：工作目录 → 硬件自检 → 档位（轻量/均衡/极致）→ 可选 LLM | 每步一个决策，不并列；硬件自检用人话给结论 + 建议档位 |
| **新建任务** | 单一输入框（链接/文件）+ 3 个折叠开关（分离/转写档/润色） | Enter 即开始；粘贴即识别类型（URL vs 路径） |
| **任务看板** | 4 列状态或单列时间线（默认单列，按状态分组） | 每卡显示：阶段 + `128/240 段` + 剩余 + 显存；失败卡直接给「重试/跳过阶段/查看日志」 |
| **单集详情** | 上：波形 + 播放器；下：逐字稿 / 润色稿 / 字幕 / 元数据 四 Tab | 点句子 → 跳播放；低置信度黄色左边线；`[?]` 标记可编辑 |
| **模型中心** | 三段：已装 / 可装 / 下载中；显示体积、显存需求、许可 | 「安装基础套件」一键；镜像源切换；磁盘预算条 |
| **设置 · Provider** | 列表 + 详情；模型表格每行可展开参数 | 填 URL+Key → 「刷新」→ 出现模型 → 点行展开参数面板 → 能力字段置灰带说明 |
| **设置 · 硬件** | 后端、显存、CUDA 版本、手动锁定后端 | 「重算显存基准」；锁定后端时红字提示「不再自动降级」 |

## 8. 组件规范

| 组件 | 规范 |
|---|---|
| **按钮** | 主：`--lamp` 底 + `--ink` 字，2px 圆角，高 36px；次：透明底 + 1px `--line-hi` 边 + `--bone` 字；危险：透明底 + `--fail` 边与字 |
| **进度条** | 高 4px，轨道 `--line`，填充 `--lamp`；**不用条纹动画**；右侧等宽数字 `128/240` |
| **状态点** | 6px 圆；running=`--lamp` 呼吸（1.6s，opacity 0.4↔1）；done=`--bone-dim`；fail=`--fail`；queued=`--line-hi` |
| **表格** | 无斑马纹；行高 40px；hover 行底色 `--surface-hi`；数值列右对齐等宽 |
| **输入框** | 高 36px，`--surface` 底，1px `--line`，focus 时边变 `--lamp` 且不发光晕 |
| **Tag/徽标** | 高 20px，`--fs-micro`，1px 边，2px 圆角；**不用彩色胶囊** |
| **Tab** | 下划 1px，active 时 `--bone` 字 + 2px `--lamp` 下划线；不用药丸 |
| **空态** | 一句话 + 一个主操作；允许一处 `--lamp-glow`；禁止插画吉祥物 |
| **Toast** | 右下角，`--surface` + 1px 边，3s 自动消失；错误需手动关 |
| **图表**（波形/显存曲线） | 单色阶（`--bone-dim` 到 `--bone`）+ `--lamp` 标当前播放头；**禁多色图例** |

## 9. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| hover 底色变化 | 120 ms | `ease-out` |
| 面板展开/折叠 | 180 ms | `cubic-bezier(.2,.8,.2,1)` |
| 状态点呼吸 | 1600 ms | `ease-in-out` 循环 |
| 完成脉冲 | 200 ms 单次 | `ease-out` |

**禁止**：弹跳、缩放弹入、视差滚动、粒子、庆祝彩带、超过 250 ms 的界面过渡。

> 理由：这是仪表，不是营销页。动效只用来「确认操作已生效」，不用来表达情绪。

## 10. 图标与插画

- 图标：单线条（stroke 1.5px）、24×24 网格、`--bone-dim`（active 时 `--bone`），不用填充图标。
- **不使用 emoji 作为功能图标**（可用于日志文本）。
- 插画：只允许在空态使用**一行等宽字符构成的 ASCII 波形**，不用 3D/扁平插画人物。
- Logo：`S` 字标 + 一条 12px 的琥珀竖线（代表 stem 分离的「轨道」），单色可用。

## 11. 反模式清单（看到即返工）

| ❌ 反模式 | 为什么 |
|---|---|
| 蓝紫渐变、紫粉光晕 | AI 味默认审美，taste 红线 |
| 大圆角卡片 + 投影堆叠 | 移动端卡片套路，与"精密仪表"冲突 |
| 多处发光/多处强调色 | 破坏「单一光源」，视觉噪音 |
| emoji 当状态图标 | 廉价化，跨平台渲染不一 |
| 居中长文本 / 居中表单 | 瑞士平面禁止；阅读效率低 |
| 三级以上灰色 + 五级字号 | 层级混乱 |
| 进度条条纹动画 | 假装在动，且不提供信息 |
| 图表多色分类 | 见过即廉价；本产品数据维度少，不需要 |
| 暗底冷白光 | 会变成「停尸房」（辅基因明确禁止） |
| 庆祝动画/彩带 | 工具不是玩具 |

## 12. 可访问性与 DPI

- 全键盘可达：`Tab` 顺序按视觉顺序；`Ctrl+K` 命令面板；`Esc` 关面板。
- 焦点环：2px `--lamp` 外描，**不依赖颜色单独传达状态**（失败同时给图标 + 文本）。
- 125% / 150% DPI：所有尺寸用 `rem`/`px` 混用需在 `@media (min-resolution)` 下验证；左栏 240px 在 150% 下允许 1.25 倍。
- 减少动效：尊重 `prefers-reduced-motion`，关闭呼吸与脉冲。

## 14. 双主题 token 对照（CHG-0007）

两套主题共享**同一组语义名**，组件只写语义名、不写具体颜色。新增主题只需补一份变量块。

### 14.1 变量表

| 语义 token | 明亮 | 暗黑 | 用途 |
|---|---|---|---|
| `--bg` | `#f7f7f5` | `#0a0b0d` | 页面底（明亮不用纯白，防刺眼） |
| `--surface` | `#ffffff` | `#14171b` | 面板 |
| `--surface-hi` | `#f1f1ee` | `#1b1f25` | hover / active |
| `--surface-lit` | `#fffdf6` | `#1d2128` | **光源面**（运行中任务卡） |
| `--text-1` | `#14161a` | `#e9e6e0` | 正文 |
| `--text-2` | `#4a4f57` | `#9aa0a6` | 次级 |
| `--text-3` | `#6b7076` | `#7d848c` | 微文字 / 元数据 |
| `--line` | `#e3e4e1` | `#23272e` | 1px 分隔线 |
| `--line-hi` | `#cbcdc9` | `#343941` | 强调边 / 完成态进度条 |
| `--lamp` | `#8a5f0e` | `#c9a227` | 强调色（可作**文字**） |
| `--lamp-fill` | `#c9a227` | `#c9a227` | 强调底色（配 `--lamp-ink` 深字） |
| `--lamp-ink` | `#1a1405` | `#0a0b0d` | 强调底上的字色 |
| `--fail` | `#b4433a` | `#b4433a` | 失败（仅图标与 1px 边） |
| `--glow` | 暖纸色 16% | 琥珀 10% | **唯一光源**径向渐变 |

### 14.2 “单一光源”的两种物理表达

| 场景 | 明亮 | 暗黑 |
|---|---|---|
| 运行中任务卡 | 暖纸底 `#fffdf6` + 琥珀左竖线 + 极淡暖晕 | 受光面 `#1d2128` + 琥珀左竖线 + 暗场暖晕 |
| 已完成进度条 | `--line-hi`（沉下去） | `--line-hi`（沉下去） |
| 主按钮禁用态 | 中性 `--surface-hi` + `--text-3`，不假装成淡琥珀 | 同左 |

### 14.4 语言与主题的组合

| 维度 | 值 | 默认 | 持久化键 | URL 覆盖 |
|---|---|---|---|---|
| 主题 | `light` / `dark` | `prefers-color-scheme` | `stemscribe.theme` | `?theme=` |
| 语言 | `zh` / `en` | `navigator.language` | `stemscribe.lang` | `?lang=` |

优先级：URL > localStorage > 系统。URL 覆盖**不写回** storage（用于截图与深链，不污染用户偏好）。
语言名 (`中文` / `EN`) 固定不翻译；其余文案零硬编码，由 `scripts/i18n-check.sh` 守卫。
