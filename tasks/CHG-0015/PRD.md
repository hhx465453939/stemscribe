# CHG-0015 · PRD · Core Pipeline

## 1. 用户问题（一句话）

我把视频拖进软件，它应该**自动把人声抽出来、再转成 txt**；现在它没有抽人声，模型还不是最好的，拖进去也没反应。

## 2. 用户故事

| # | 故事 | 现在 | 期望 |
|---|---|---|---|
| U-1 | 我把带 BGM 的视频拖进窗口 | 没反应 / 要手打路径再点开始 | 立刻进队列并自动开跑 |
| U-2 | 我一次拖 5 个视频 | 只能一个个来 | 5 个自动排队，串行跑完 |
| U-3 | 我期望先抽人声 | 分离是空实现，直接拿原声转写 | 先跑 UVR5 抽 vocal，再转写 vocal |
| U-4 | 我要最好质量 | 默认 median 级模型 | 默认最大/最好的模型 |
| U-5 | 我的机器一般 | 可能 OOM 或很慢 | 能跑；降档时明确告诉我 |
| U-6 | 我只要文本 | 只有 json/md/srt/vtt | 还要一个 `transcript.txt` |

## 3. 主流程（必须无脑可走）

```
拖入 [v1, v2, ...]
   └─► 队列（串行）
         └─► demux（视频→音频）
               └─► separate（UVR5，必选）→ vocals.wav
                     └─► transcribe（最大模型，vocals.wav）
                           └─► align → export（txt/srt/vtt/md/json）
```

任何一步缺失依赖：**失败并告诉我装什么**，不许跳过继续。

## 4. 基本 UX（本 CHG 必须有）

| 项 | 要求 |
|---|---|
| 拖入 | 桌面窗口拖入多个视频，立即入队 |
| 队列 | 每项显示状态/进度；串行；失败不阻塞后续 |
| 输出目录 | 可选，留空用默认 |
| 模型 | 可选，默认最大；只列已安装项 |
| 语言 | 可选，默认中文 |
| 分离 | 固定开启，不提供关闭 |
| 产物 | 打开产物目录；txt 可直接读 |

## 5. 非目标

VAD、逐字稿查看器、取消运行、卸载模型、润色、URL 导入。

## 6. 成功判据

1. 拖入 1 个带 BGM 的视频，不点任何“开始”，最终得到 `transcript.txt`。
2. 拖入多个视频，全部按顺序完成。
3. 分离先于转写，且转写输入是 vocals。
4. 默认模型是最大可用模型；降档可见。
5. 缺依赖时失败并给出安装指引，不静默跳过。

## 7. 约束

- 音视频不出本机。
- 模型/运行时按需下载，安装包不随模型。
- 不引入新的前端框架依赖。
- 文案中英双语（`i18n-check` 零硬编码 CJK）。
