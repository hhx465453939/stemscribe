# CHG-0013 · PRD · UX Essentials

## 1. 用户问题

「能用」和「好用」之间差的是这些基本功能：不能选文件、不能选输出位置、改了参数没反应、跑完找不到产物。

## 2. 用户故事

| # | 故事 | 现在 | 期望 |
|---|---|---|---|
| U-1 | 我在参数页把语言改成中文，然后转一个中文视频 | 没变化（参数没发出去） | 真的按中文转 |
| U-2 | 我想把产物放到 D:\转写结果 | 没有这个选项 | 设置里能选，产物落在那儿 |
| U-3 | 我拖 3 个视频进来 | 拖不进来 | 3 个进队列，自动跑完 |
| U-4 | 跑完了想打开文件夹看 | 只能复制路径粘贴到资源管理器 | 一键打开 |
| U-5 | 我想换更大的模型 | 只能改配置文件 | 界面上选 |

## 3. 非目标

卸载、单集查看、通知、引导：本 CHG 不做（见审计表 P1/P2）。

## 4. 成功判据

1. 参数改了**真的生效**，且产物元数据能证明。
2. 输出目录可选，产物落点可预测。
3. 多文件一次排入、自动跑完。
4. 产物目录一键可达。
5. 模型可为单个任务选择。
