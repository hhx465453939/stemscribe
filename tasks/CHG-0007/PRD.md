# PRD · CHG-0007 · 双主题与双语

> 上游需求来源：owner 会话指令 2026-11-17
> 「美术风格明亮风格+暗黑风格，两个都要有，还要中英双语。」

## 1. 问题与用户

| 用户 | 场景 | 现状的痛 |
|---|---|---|
| 夜间长时间建档的研究者（主用户） | 深夜连续处理 20–50 集，屏幕是暗环境里唯一光源 | 现有界面只有暗色，**没有明亮可选**；这是需求已满足的方向 |
| 白天/投影/录屏演示的用户 | 会议室投屏、录教程、截图进文档 | 暗底在投影仪上发灰、在打印件上糊成黑块 |
| 非中文用户（开源后的主力增量） | 从 GitHub 进来，看不懂「新建任务 / 模型中心」 | **界面全中文硬编码**，无法使用 |

真实需求不是"加个开关"，而是：**同一套设计基因在两种光照条件下都成立，并且文案不绑定语言。**

## 2. 目标

| # | 终态（可判定） |
|---|---|
| G-1 | 明亮 / 暗黑两套主题，切换即时生效、刷新后保持、默认跟随系统 |
| G-2 | 中 / 英两套文案，切换即时生效、刷新后保持、默认跟随浏览器语言 |
| G-3 | 四种组合（明/暗 × 中/英）**都无排版溢出、无未翻译残留** |
| G-4 | 两套主题下正文与次级文字对比度均 ≥ 4.5:1（可实测） |
| G-5 | 组件内**零硬编码可见文案**（可脚本校验） |
| G-6 | README 中英双版，含两主题截图，与界面同源风格 |

## 3. 非目标

- ❌ 主题自定义（用户自选色板 / 上传主题）——4 色封顶是设计约束，开放即失控
- ❌ 第三语言（日/韩/俄）——本 CHG 只做中英，字典结构保证后续可加
- ❌ RTL（阿拉伯语等）——需要布局镜像，另立项
- ❌ 字体切换（用户自选字体）
- ❌ 服务端语言协商（桌面端无服务端）

## 4. 功能需求

### P0（本 CHG 必须全部满足）

| ID | 需求 | 说明 |
|---|---|---|
| F-01 | 明亮主题 | 白底瑞士平面；不得是暗色的机械反色（见 ADR-009） |
| F-02 | 暗黑主题 | 保留现有"单一光源"暗场表达 |
| F-03 | 默认跟随系统 | `prefers-color-scheme`，用户未显式选择时生效 |
| F-04 | 手动切换 + 持久化 | 侧栏分段控件；写 `localStorage` |
| F-05 | URL 覆盖 | `?theme=light\|dark`、`?lang=zh\|en`，优先级最高（用于截图/深链） |
| F-06 | 中/英双语 | 全部可见文案，含表格、空态、提示、错误 |
| F-07 | 语言持久化 + 系统默认 | `navigator.language` 以 `zh` 开头取中文，否则英文 |
| F-08 | 无 FOUC | 首帧即为正确主题（内联 boot script，绘制前写 `data-theme`） |
| F-09 | 语言名不自译 | 语言项固定显示 `中文` / `EN`，不随界面语言翻译（已知可用性陷阱） |
| F-10 | 可访问性 | 切换控件 `role="group"` + `aria-pressed`；两主题对比度 ≥4.5:1 |

### P1（结构预留，不在本 CHG 实现）

- 第三语言接入（字典加一份即可，不需改组件）
- 时间/数字本地化（`Intl.DateTimeFormat`，当前时间码是纯计时格式，不涉及时区）

## 5. 交互

侧栏底部两组分段控件，常驻可见（不藏进二级菜单——它们是被高频切换的偏好）：

```
主题   [ 明亮 | 暗黑 ]
语言   [ 中文 | EN ]
```

- 点击即生效，无确认、无弹窗
- 控件本身也必须随主题变色（在明亮主题下不能仍是暗色控件）
- 状态通过底色差 + 文字色表达，不只靠颜色（`aria-pressed` 同步）

## 6. 验收演示脚本

1. 默认系统为暗色 → 首次打开即为暗黑主题、界面文案跟随系统语言
2. 点「明亮」→ 立即变白底；刷新 → 仍是明亮
3. 点「EN」→ 全部文案变英文（含"新建任务/资料库/模型中心/设置"与设置页能力表）
4. 打开 `?theme=dark&lang=en` → 暗色 + 英文（覆盖已存偏好，但不写回）
5. 四种组合逐页截图：`/`、`/library`、`/models`、`/settings` → 无截断、无中文残留
6. 暗色下"运行中"任务卡有暖光 + 琥珀左竖线；明亮下同一位置有暖纸色底 + 琥珀左竖线（**语义一致、物理不同**）
7. 用亮度计/脚本核对：两主题正文与次级文字对比度 ≥ 4.5:1
8. 关闭 JS 后首帧主题不闪白（boot script 早于绘制）

## 7. 边界

| 不做 | 理由 |
|---|---|
| 主题跟随时间自动切换（日落后变暗） | 猜测用户意图，容易被误判为 bug |
| 每页独立主题 | 偏好是全局的，局部主题只会造成混乱 |
| 机器翻译接入 | 文案是产品语气的一部分，必须人工定稿 |
