# CHG-0011 · PRD · Provisioning

## 1. 用户问题（一句话）

模型中心告诉我「未安装」，却没有地方可以点安装——我只能去命令行敲命令。

## 2. 用户故事

| # | 故事 | 现在 | 期望 |
|---|---|---|---|
| U-1 | 我打开模型中心，看到 `Whisper Base · 未安装`，想装它 | 只能看，点不了 | 有「安装」按钮，点了就开始 |
| U-2 | 装了 30 秒，我想知道进展 | 无 | 显示「安装中 42%」或至少「安装中」 |
| U-3 | 装完了 | 需要手动刷新 | 自动刷新，该项进入「已安装」 |
| U-4 | 我点了某个校验值未实测的模型 | 无提示 | 明确拒绝：「sha256 未实测，暂不可安装」 |
| U-5 | 装好 GPU 运行时后，我想确认真的用上了 | 无从判断 | 侧栏后端从 `cpu` 变 `vulkan` |

## 3. 非目标

- 不做卸载、不做并发安装、不做断点续传的新机制。
- 不做镜像源切换（registry 已固定 hf-mirror，另立）。

## 4. 成功判据

1. 任一「未安装」项可在一次点击后开始安装，且界面立刻有反馈。
2. 安装完成的判定来自**磁盘实存**，不是界面自己记的账。
3. 校验值缺失的条目被拒绝，且理由写在界面上。
4. 装完 GPU 运行时，`/api/capabilities` 的 `backend` 真的改变。
5. CLI 行为不因抽取而退化。

## 5. 度量

| 指标 | 目标 |
|---|---|
| 点击到首个反馈 | ≤ 500 ms |
| 假进度条数量 | 0（无回调即不显示百分比） |
| 校验缺失仍安装的次数 | 0 |
